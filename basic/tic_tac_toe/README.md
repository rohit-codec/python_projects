# Tic Tac Toe – Python GUI

A simple **Tic Tac Toe game with a graphical user interface (GUI)** built using Python and Tkinter.

## Features

- Two-player game: Player X vs Player O
- Interactive 3 × 3 game board
- Detects winner automatically
- Detects draw
- New Game button to restart
- Simple and beginner-friendly code
- Uses Python's built-in `tkinter` library

## Requirements

- Python 3.x
- Tkinter

Tkinter is included with most standard Python installations.

## How to Run

1. Download or copy the project.
2. Open a terminal in the project folder.
3. Run:

```bash
python main.py
```

On some systems you may need:

```bash
python3 main.py
```

## How to Play

1. Player X starts the game.
2. Click any empty square to place your mark.
3. Player O takes the next turn.
4. The first player to get three marks in a row wins.

Winning patterns include:

- Horizontal
- Vertical
- Diagonal

If all nine squares are filled and nobody has three in a row, the game is a draw.
