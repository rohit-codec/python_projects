# 🎯 Number Guessing Game

A simple **Number Guessing Game with a Graphical User Interface (GUI)** built using Python and Tkinter.

The computer randomly selects a number between **1 and 100**, and the player has to guess it. After every guess, the game tells whether the actual number is **higher or lower** and keeps track of the number of attempts.

## ✨ Features

* 🎲 Random number between **1 and 100**
* ⌨️ User-friendly input field
* 📈 Shows if the number is higher
* 📉 Shows if the number is lower
* 🎯 Displays the number of attempts
* 🎉 Shows the result when the number is guessed
* 🔄 **Play Again** button
* ⚠️ Handles invalid input
* 🖥️ Simple graphical interface

## 🛠️ Technologies Used

* **Python 3**
* **Tkinter**
* **Random module**

## 🎮 How to Play

1. The computer generates a random number between **1 and 100**.
2. Enter your guess in the input box.
3. Click the **GUESS** button.
4. The game will tell you:

   * 📈 **The number is HIGHER**
   * 📉 **The number is LOWER**
5. Continue guessing until you find the correct number.
6. The game displays the total number of attempts.
7. Click **PLAY AGAIN** to start a new game.
