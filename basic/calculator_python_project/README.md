# Python Calculator

A simple desktop calculator built with **Python** and **Tkinter**.

## Features

- Addition, subtraction, multiplication, and division
- Percentage operator
- Decimal calculations
- Parentheses
- Square (`x²`)
- Square root (`√`)
- Clear button
- Backspace button
- Error handling for invalid expressions
- Keyboard support:
  - `Enter` → Calculate
  - `Esc` → Clear

## Requirements

- Python 3.x
- Tkinter (usually included with standard Python installations)

## How to Run

1. Install Python 3 from the official Python website.
2. Open a terminal/command prompt.
3. Navigate to the project folder.
4. Run:

```bash
python calculator.py
```

## Example

You can enter:

```text
10 + 5 × 2
```

and press `=` or `Enter`.

The calculator evaluates the expression and displays the result.
